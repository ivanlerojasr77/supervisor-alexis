Alexis — análisis de reportes

Alexis puede pedir el reporte en voz alta, recibir una pregunta dictada, clasificarlo y leer el resultado.

La aplicación no conserva archivos ni historial; el servidor puede usar almacenamiento temporal durante la carga. Un PDF escaneado requiere OCR. Para dictado, el navegador debe admitir reconocimiento de voz y tener permiso para usar el micrófono.
